## Selected Projects

### [Bidirectional AHB-Lite ↔ APB4 Bridge](https://github.com/abdulmageed20/Bidirectional-AHB-Lite-APB4-Bridge)
Dual-clock bidirectional protocol bridge with asynchronous FIFOs, CDC handling, assertions, functional coverage, regression automation, and Vivado implementation evidence.

### [RV32I Five-Stage Core](https://github.com/abdulmageed20/RV32I-Five-Stage-Core)
Five-stage RISC-V processor with forwarding, load-use hazard handling, branch recovery, load/store support, MMIO, and directed verification.

### [AES-128 UVM Verification](https://github.com/abdulmageed20/AES-UVM-Verification)
UVM verification of an AES-128 encryption core using an independent Python golden model, functional coverage, RTL code coverage, and toggle coverage.

### [SPI UVM Verification](https://github.com/abdulmageed20/SPI-UVM-Verification)
UVM verification environment for SPI Slave, RAM, and Wrapper using assertions, independent golden models, scoreboards, and coverage.

### [DSP48A1 Design and FPGA Implementation](https://github.com/abdulmageed20/DSP48A1-Design-and-FPGA-Implementation)
Parameterized DSP48A1 RTL design with directed simulation, linting, synthesis, timing analysis, and routed FPGA implementation.

### [FIFO Verification](https://github.com/abdulmageed20/FIFO-Verification)
Synchronous FIFO verification with assertions, constrained-random stimulus, scoreboard checking, functional coverage, and regression.
